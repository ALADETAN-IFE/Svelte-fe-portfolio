# Frontend Wizards — Stage 5b @channel

## Build an Interactive Developer Portfolio with Svelte

### 🎯 Objective

Build a highly interactive, visually impressive developer portfolio using Svelte or SvelteKit.
This is not a static “about me” website.

Your portfolio must feel:

- immersive
- animated
- engineered
- memorable
- production-grade

The goal is to showcase:

- frontend engineering skill
- interaction design
- performance optimization
- creative thinking
- Svelte mastery

Your portfolio should feel like an experience, not just a page.

### 🧠 What the Portfolio Should Do

The portfolio must:

- present your projects and skills
- demonstrate advanced frontend interactions
- showcase smooth animations and transitions
- maintain excellent performance
- feel unique and intentional

Think:

- futuristic developer portfolio
- interactive product showcase
- immersive frontend experience
- cinematic storytelling

### 🧩 Required Features

#### 1️⃣ Built with Svelte or SvelteKit

You must use:

- Svelte
- SvelteKit

The application should demonstrate:

- component composition
- reactive state handling
- proper routing
- clean architecture

Bonus:

- server-side rendering
- static generation
- progressive enhancement

#### 2️⃣ Hero Section

Your landing section must immediately impress.

Required:

- strong visual identity
- smooth entrance animations
- responsive layout
- clear call-to-action

Must include:

- your name/title
- short introduction
- social/contact links
- resume/download CTA

Bonus:

- animated background
- particle systems
- 3D effects
- cursor interactions
- shader effects

#### 3️⃣ Projects Showcase

Display your projects dynamically.

Each project card/page should include:

- title
- description
- technologies used
- screenshots/videos
- live demo link
- GitHub repository

Required interactions:

- hover effects
- animated transitions
- responsive layouts

Bonus:

- project filtering
- category tabs
- cinematic project transitions
- expandable project modals

#### 4️⃣ Smooth Animations & Transitions

Animation quality is heavily evaluated.

Expected:

- smooth page transitions
- staggered reveals
- motion consistency
- performant animations

You must avoid:

- laggy animations
- excessive motion
- janky scroll effects

Suggested tools:

- Svelte Motion
- GSAP
- Motion One
- native Svelte transitions

#### 5️⃣ Responsive & Adaptive Design

Your portfolio must work beautifully on:

- desktop
- tablet
- mobile

Requirements:

- adaptive layouts
- responsive typography
- touch-friendly interactions
- accessible navigation

#### 6️⃣ Performance Optimization

Your portfolio should load fast and remain smooth.

You will be evaluated on:

- Lighthouse performance
- responsiveness
- animation smoothness
- optimized assets
- lazy loading
- bundle optimization

Bonus:

- image optimization
- route-level code splitting
- reduced motion support

#### 7️⃣ Accessibility

Accessibility is required.

Your application must:

- support keyboard navigation
- have visible focus states
- use semantic HTML
- include alt text where necessary
- maintain readable contrast

Bonus:

- screen reader enhancements
- skip navigation links
- motion accessibility controls

#### 8️⃣ Contact Section

Include a functional contact experience.

Must include:

- contact form
- mail integration

Optional:

- animated form interactions
- validation feedback
- email sending integration
- scheduling links

#### 9️⃣ Theme Support

Your portfolio must support:

- dark mode
- dynamic theming

Bonus:

- theme persistence
- custom accent colors
- animated theme switching
